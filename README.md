# Volleyball Management

Plataforma PWA para clubes de voleibol (Next.js + Supabase).

## Estado
Primeiro incremento: autenticação, estrutura multi-equipa, agenda individual e wellness. Não está ainda publicado.

## Instalação
1. `npm install`
2. Copiar `.env.example` para `.env.local` e preencher valores públicos do projeto Supabase.
3. `npm run dev`

O acesso aos dados depende das políticas RLS da base de dados. Nunca guardar chaves privadas no GitHub.

## Próximos incrementos
Gestão de membros e horários; editor de treinos; participantes e presenças; periodização; jogos; notificações; importação DVW.
